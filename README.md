# Проект Домашняя работа 

## Данный проект представляет собой учебное ядро e-commerce системы, реализованное на языке Python с использованием объектно-ориентированного программирования (ООП)..

## Установка:

1. Клонируйте репозиторий:
'''
https://github.com/abdlovd/ecommerceproject
'''

2. Установите зависимости:
'''
pip install -r requirements.txt

3. В основе проекта лежит работа с сущностями (объектами), которые имеют собственные параметры и поведение. В качестве предметной области выбрана электронная коммерция (e-commerce), так как она наглядно демонстрирует взаимодействие объектов, инкапсуляцию данных и использование различных механизмов ООП.

На текущем этапе в проекте не реализуется система оплаты, однако создаётся логическая основа интернет-магазина. Реализованное ядро может быть в дальнейшем расширено и использовано для разработки сайта, API или Telegram-бота.

В проекте реализованы две ключевые сущности:

Product — товар

Category — категория товаров

Класс Product описывает товар с такими характеристиками, как название, описание, цена и количество на складе. Цена товара инкапсулирована с помощью приватного атрибута, а доступ к ней осуществляется через геттеры и сеттеры с проверкой корректности значения. Также реализовано строковое представление товара и возможность сложения товаров для подсчёта общей стоимости склада.

Класс Category описывает категорию товаров и содержит приватный список продуктов. Добавление товаров в категорию осуществляется только через специальный метод, что обеспечивает контроль над данными. Для просмотра списка товаров реализован геттер. Класс также содержит атрибуты класса, которые автоматически отслеживают общее количество категорий и товаров. 

4. Дополнительно в проекте:
а) Реализован класс-метод для создания товара из словаря;
б) Добавлена логика объединения одинаковых товаров;
в) Реализована перегрузка операторов; 
г) Создан вспомогательный класс для итерации по товарам категории; 

5. Написаны тесты с использованием pytest для проверки новой и существующей функциональности.

Проект направлен на практическое освоение принципов ООП, таких как инкапсуляция, работа с классами и объектами, использование приватных атрибутов, геттеров и сеттеров, а также тестирование кода.
